# Ограничение мощности при разгоне

Ограничитель поддерживает активную электрическую мощность двигателя за счёт
динамического изменения предела тока. До достижения заданной мощности привод
работает с обычным токовым ограничением, затем ток уменьшается по мере роста
скорости. Штатное ограничение `refs.Iq_ref` всегда имеет приоритет.

## Настройка

Уставка хранится в `refs.power_ref` в формате Q24 и задаётся в относительных
единицах от `drv_params.power`:

```
refs.power_ref = P_limit_W / P_base_W
```

При текущей базовой мощности 300 Вт:

- `1.0` — 300 Вт (значение по умолчанию);
- `0.5` — 150 Вт;
- `0.25` — 75 Вт;
- `0` — отключить ограничитель после инициализации.

Через CANopen уставка доступна по `0x5174:0F` как Q24. Тот же адрес памяти
доступен в сыром виде по `0x5174:10`. В текущем XML словаря эти два объекта
по-прежнему отображаются под служебным именем `DebugW4`.

При перегенерации словаря нужно сохранить привязки `0x5174:01..04` и
`0x5174:0F..10`, поскольку исходный `cood.xml` имеет кодировку, не совпадающую
с кодировкой исходных файлов C, и оставлен без изменения.

Для наблюдения доступны:

- `0x5174:01` — ошибка мощности в Q24 (`sm_ctrl.power_error`);
- `0x5174:03` — действующий динамический предел тока в Q24
  (`sm_ctrl.power_iq_limit`);
- `sm_ctrl.power_limiting` — флаг активного ограничения.

Ограничитель включён в частотно-токовый режим и векторные режимы синхронного и
асинхронного двигателей, включая их позиционные варианты. Режим U/f не
поддерживается, поскольку в нём нет внутреннего контура тока. Для ДПТ и SRM
нужен отдельный расчёт мощности по их собственным каналам тока и напряжения.
