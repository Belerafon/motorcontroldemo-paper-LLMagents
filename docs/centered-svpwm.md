# Центрированная векторная ШИМ

В проект добавлен тип `PWM_TYPE_CENTERED_SV` со значением `6`.

Алгоритм преобразует задание `UalphaRef`, `UbetaRef` в три фазных потенциала
и добавляет к ним общую составляющую

`U0 = -(max(Ua, Ub, Uc) + min(Ua, Ub, Uc)) / 2`.

Общая составляющая не меняет линейные напряжения. Она центрирует максимальный
и минимальный фазные потенциалы относительно середины диапазона ШИМ, то есть
поровну распределяет свободное время между верхним и нижним нулевыми
векторами. Поэтому до достижения ограничения ни одна фаза не фиксируется к
верхней или нижней шине.

Круговой линейный диапазон:

- синусоидальная ШИМ: `0,866` о.е.;
- центрированная SVPWM: `1,0` о.е.

Прирост доступной амплитуды составляет примерно 15,5 %. При достижении
`U_lim` вектор пропорционально ограничивается, а `pwm.ULimitation`
устанавливается в `1`. Перемодуляция в новом режиме не используется.

## Выбор и настройка

| Параметр | CANopen | Представление | Значение |
|---|---|---|---|
| `pwm.PWM_type` | `0x5105:0C` | беззнаковое 16-битное целое | `6` — центрированная SVPWM |
| `pwm.U_lim` | `0x5105:03` | знаковое IQ24 | безопасный диапазон `0..1,0` о.е. |
| `pwm.ULimitation` | `0x5105:0D` | знаковое 16-битное целое, только чтение | `1` при ограничении |

Скомпилированное безопасное значение `U_lim` остается равным `0,866` о.е.,
поэтому старое поведение после сборки не меняется. Для использования полного
линейного диапазона нового режима нужно временно установить в RAM
`PWM_type = 6` и `U_lim = 1,0`.

Изменения через CANopen относятся к рабочим значениям RAM. При сбросе они
могут быть восстановлены из EEPROM штатной инициализацией словаря объектов.
Эта реализация не выполняет запись в EEPROM и не меняет правила постоянного
сохранения параметров.

## Проверка на программной модели

Сценарий разгона поддерживает временный выбор режима и гарантированно
восстанавливает прежние значения после `stop`:

```powershell
python tests\e2e\run.py vector-500 --pwm-type 6 --u-limit-pu 1.0
```
