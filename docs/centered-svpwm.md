# Центрированная векторная ШИМ

Режим `PWM_TYPE_CENTERED_SV` (`pwm.PWM_type = 6`) реализует классическую
центрированную SVPWM. К трем фазным потенциалам добавляется одинаковая
синфазная составляющая, поэтому линейные напряжения не меняются, а нулевой
вектор равномерно распределяется между состояниями верхней и нижней шин.

До ограничения напряжения ни одна фаза не фиксируется на шине. При достижении
границы шестиугольника фазные потенциалы пропорционально уменьшаются с
сохранением направления вектора, а `pwm.ULimitation` устанавливается в `1`.
По сравнению с синусоидальной ШИМ доступный линейный диапазон напряжения
увеличен с `0,866` до `1,0` о.е., то есть примерно на 15,5 %.

## Управление

- `0x5105:0C`, `pwm.PWM_type`: беззнаковое 16-битное целое; значение нового
  режима — `6`. Скомпилированное значение профиля по умолчанию — `1`
  (синусоидальная ШИМ).
- `0x5105:03`, `pwm.U_lim`: знаковое IQ24; профиль допускает `0..1` о.е.,
  значение по умолчанию — `0,866` о.е. Для полного линейного диапазона
  центрированной SVPWM используется `1,0` о.е.
- `0x5105:0D`, `pwm.ULimitation`: знаковое 16-битное диагностическое значение
  только для чтения; `1` означает активное ограничение.
- `0x5105:04..06`, `pwm.GammaA..GammaC`: беззнаковые 16-битные значения
  сравнения таймеров для диагностики.

Для безопасного A/B-сравнения меняйте `pwm.PWM_type` и `pwm.U_lim` временно в
RAM при остановленном приводе. После сброса значения могут быть восстановлены
из EEPROM штатной инициализацией CANopen. Эта реализация сама ничего в EEPROM
не записывает; постоянное сохранение выполняется только отдельной штатной
процедурой по явной команде пользователя.
