# Автоматическое ослабление поля

Модуль `field_weakening` работает в режимах векторного управления синхронным
двигателем `CTRL_RUN_VECTOR_SM` (5) и `CTRL_RUN_VECTOR_SM_ENCODER_POS` (10).
Он контролирует амплитуду задания напряжения `Ud/Uq`. Когда она превышает 97 %
доступного `pwm.U_lim`, интегральный регулятор плавно увеличивает отрицательный
ток `Id`. Когда запас напряжения возвращается, `Id` автоматически уменьшается
по модулю до нуля.

Задания `Id` и `Iq` всегда вписываются в окружность `refs.Iq_ref`. Для расчёта
допустимого `Iq` используется большее по модулю из задания и фактического `Id`,
поэтому ограничение сохраняется и при переходных процессах. Максимальный ток
ослабления поля по умолчанию равен 90 % `refs.Iq_ref`.

## Настройка и A/B-проверка

Новые объекты словаря не добавлялись: используются свободные отладочные
переменные существующей группы `0x5174`.

| Переменная | Индекс/подындекс | Представление | Назначение |
|---|---|---|---|
| `DebugW3` | `0x5174:0D/0E` | знаковое 32-битное целое | `0` — скомпилированный режим (по умолчанию включён), `>0` — принудительно включить, `<0` — отключить и получить прежнее `Id=0` |
| `DebugW4` | `0x5174:0F/10` | IQ24 | множитель усиления; `0` — штатный множитель 1,0, положительное значение ограничивается диапазоном 0,1…4,0 |
| `Debug1` | `0x5174:01/02` | IQ24 тока | текущее автоматическое задание `Id` |
| `Debug2` | `0x5174:03/04` | IQ24 напряжения | ошибка амплитуды напряжения относительно цели |
| `Debug3` | `0x5174:05/06` | 16-битное целое | признак активного отрицательного `Id` |
| `Debug4` | `0x5174:07/08` | 16-битное целое | признак ограничения в модуле ШИМ |

Скомпилированные значения: цель напряжения 0,97 от `pwm.U_lim`, усиление за
такт 0,0025 и предел `|Id|` 0,90 от общего тока. При `CTRL_STOP` состояние
регулятора и диагностические переменные сбрасываются. Изменения `DebugW3` и
`DebugW4` являются временными значениями RAM, пока пользователь отдельно не
выполнит сохранение параметров. Код этой функции EEPROM не записывает.

## Проверка

Сценарий управляет только программной моделью, временно задаёт 700 об/мин,
гарантированно отправляет `stop` и восстанавливает уставки:

```powershell
python tests\e2e\run.py field-weakening
```

Он проверяет достижение скорости выше базовой, появление отрицательного `Id`,
стабилизацию амплитуды напряжения и соблюдение общей окружности заданий тока.
