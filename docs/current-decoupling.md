# Компенсация перекрёстных связей регуляторов тока

В режимах `CTRL_RUN_I2F`, `CTRL_RUN_VECTOR_SM` и
`CTRL_RUN_VECTOR_SM_ENCODER_POS` после PI-регуляторов добавляются индуктивные
составляющие прямой связи:

```text
ud_ff = -omega_e * Ls * iq
uq_ff =  omega_e * Ls * id
```

Знаки соответствуют уравнениям синхронной модели и принятому в проекте
преобразованию Парка. Коэффициент пересчитывается в фоне из `drv_params.Ls`,
`drv_params.freq_nom`, `drv_params.I_nom` и `drv_params.U_nom`:

```text
k_cross = 2*pi*freq_nom*Ls*I_nom/U_nom
```

`Ls` хранится в RAM как Q24 в генри и отображается через масштаб 1000 в мГн.
Скорость, токи, напряжения и коэффициент усиления в быстром контуре имеют
формат IQ24.

## Управление и диагностика

Использованы свободные переменные существующей группы CANopen `0x5174`; сам
словарь и сгенерированные `cood1.c`/`cood2.c` не изменялись.

| Переменная | Индекс:подындекс | Представление | Назначение |
|---|---:|---|---|
| `DebugW3` | `0x5174:0x0E` | знаковое целое 32 бит | Точное значение `1` включает компенсацию; любое другое значение выключает её |
| `DebugW4` | `0x5174:0x0F` | IQ24 | Усиление компенсации; старое/дефолтное значение `0` трактуется как `1.0` |
| `Debug1` | `0x5174:0x01` | IQ24, о.е. напряжения | Рассчитанное `ud_ff`, только чтение |
| `Debug2` | `0x5174:0x03` | IQ24, о.е. напряжения | Рассчитанное `uq_ff`, только чтение |

Безопасный диапазон `DebugW4` — `0...2`. Отрицательное значение ограничивается
нулём, значение выше `2` — двойным усилением. Для точного возврата к старому
алгоритму нужно записать в `DebugW3` значение `0`; при этом feed-forward и его
дополнительная антивиндап-коррекция полностью исключаются.

При инициализации управления после восстановления словаря CANopen явно
устанавливаются `DebugW3 = 1` и `DebugW4 = 0` (единичное усиление), поэтому
компенсация является штатным поведением после сброса и не зависит от старых
значений отладочных переменных в EEPROM. Для безопасного A/B-отката нужно
записать `DebugW3 = 0`; это полностью возвращает прежний алгоритм до следующего
сброса. Записи через отладчик меняют только рабочую RAM. Сохранение этих
переменных в EEPROM этой доработкой не выполняется.

Суммарный вектор напряжения ограничивается по `pwm.U_lim`; ошибка внешнего
ограничения передаётся в `saterr_reg3Add` обоих PI-регуляторов на следующем
такте, чтобы интеграторы не накапливались при насыщении.

Асинхронные векторные режимы намеренно не используют этот блок: для них нужна
угловая скорость потоковой системы координат (включая скольжение) и отдельные
параметры индуктивностей рассеяния.
