# Динамическое ограничение мощности

Ограничитель работает в режимах векторного управления синхронным и
асинхронным двигателем, включая варианты с контуром положения. Он использует
измеренную активную электрическую мощность `cur_par.fPower.input` и динамически
уменьшает границу выхода регулятора скорости, то есть задание тока момента
`Iq`. На малой скорости действует штатное ограничение `refs.Iq_ref`; после
достижения заданной мощности ток уменьшается, и дальнейший разгон идет при
практически постоянной мощности.

## Настройка через существующие Debug-переменные

| CANopen | Переменная | Представление | Назначение |
|---|---|---|---|
| `0x5174:0x0E` | `DebugW3` | signed 32-bit | `0` — прежний алгоритм, `1` — ограничитель включен |
| `0x5174:0x10` | `DebugW4` | signed 32-bit, Вт | Ограничение активной мощности |
| `0x5174:0x0B` | `DebugW2` | IQ24 | Пропорциональный коэффициент; допустимо `(0; 4]`, иначе применяется `0.5` |
| `0x5174:0x01` | `Debug1` | IQ24 | Фильтрованная мощность в долях `drv_params.power`, только чтение |
| `0x5174:0x03` | `Debug2` | IQ24 | Текущая динамическая граница `Iq` в относительных единицах, только чтение |

Безопасная последовательность временной настройки в RAM:

1. При остановленном приводе записать требуемую мощность в ваттах в
   `DebugW4` через подындекс `0x10`.
2. При необходимости задать положительный `DebugW2` через IQ24-подындекс
   `0x0B`. Начинать с `0.5`.
3. Записать `1` в `DebugW3` через целочисленный подындекс `0x0E`.
4. Задать обычные `refs.speed_ref` и `refs.Iq_ref`, затем выполнить штатный
   пуск.

Значение мощности должно быть положительным. Внутренний диапазон ограничен
четырьмя номинальными мощностями `drv_params.power`; ток во всех случаях
дополнительно ограничен `refs.Iq_ref`.

При `DebugW3 != 1`, неположительном `DebugW4` или выходе из векторного режима
контур полностью возвращается к прежнему ограничению по току. Скомпилированные
значения по умолчанию `DebugW3 = 0` и `DebugW4 = 0` безопасно оставляют
ограничитель выключенным.

Параметры являются временными рабочими значениями RAM. Прошивка не выполняет
их автоматическое сохранение в EEPROM.
