# Динамическое ограничение мощности

Ограничитель работает в скоростных векторных режимах:

- `CTRL_RUN_VECTOR_SM` (режим 5);
- `CTRL_RUN_VECTOR_IM_ENCODER` (режим 9).

Внешний контур сравнивает модуль мгновенной активной мощности
`cur_par.fPower.input` с уставкой и динамически изменяет допустимый выход
регулятора скорости, то есть предел `Iq`. Для управления используется сигнал
до медленного экранного фильтра; `cur_par.power` остается фильтрованным
наблюдаемым значением. На малой скорости действует штатный предел
`refs.Iq_ref`; после достижения заданной активной мощности контур уменьшает
момент и поддерживает мощность во время разгона. Для рекуперации применяется
симметричный предел.

## Управление

Параметры используют свободные отладочные объекты и по умолчанию не сохраняются
этим алгоритмом в EEPROM.

| Назначение | Символ | CANopen | Представление | Значение |
|---|---|---:|---|---|
| Включение | `DebugW3` | `0x5174:0E` | signed 32-bit | только `1` включает; любое другое значение выключает |
| Уставка активной мощности | `DebugW4` | `0x5174:10` | signed 32-bit | ватты, строго больше нуля |
| Усиление внешнего контура | `DebugF1` | `0x5174:11` | float32 | `0` выбирает `0.4`; допустимо `(0; 1]` |
| Эффективный предел `Iq` | `Debug1` | `0x5174:01` | IQ24 | относительные единицы базового тока |
| Нормированная уставка мощности | `Debug2` | `0x5174:03` | IQ24 | относительно `drv_params.power` |
| Состояние | `Debug3` | `0x5174:05` | unsigned 16-bit | `0` выключен, `1` включен, `2` ограничивает |

Рекомендуемый начальный диапазон усиления — `0.1…0.5`. Меньшее значение
дает более плавное, но медленное ограничение; большее ускоряет реакцию и
увеличивает риск колебаний. Уставку мощности рекомендуется начинать ниже
`drv_params.power` и поднимать по результатам осциллограммы.

Безопасная последовательность временной настройки в RAM:

1. Остановить привод.
2. Записать мощность в `DebugW4`.
3. Записать усиление в `DebugF1` или оставить `0`.
4. Записать `DebugW3 = 1`.
5. Запустить скоростной векторный режим.

Для точного возврата к прежнему алгоритму достаточно записать `DebugW3 = 0`.
При сбросе значения могут быть восстановлены штатной логикой CANopen из
EEPROM, если ранее сохранялись внешним инструментом; сам ограничитель EEPROM
не записывает.
