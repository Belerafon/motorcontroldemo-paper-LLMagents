Данный репозиторий включает в себя полноценный работоспособный проект для задач управления двигателем на базе микроконтроллеров серии 1921ВК01 фирмы АО «НИИЭТ». Помимо исходного кода проекта, репозиторий содержит специализированное программное обеспечение, позволяющее производить разработку, отладку и исследование систем управления через интерфейс CAN (RS) с протоколом высокого уровня CANopen. Начинать знакомство с данным ПО следует с файла ```Описание структуры ПО MotorControlDemo.pdf```, находящегося в разделе [Downloads](https://gitflic.ru/project/belerafon/motorcontroldemo-downloads).

Состав репозитория:

- MotorControlDemo – проект с исходными кодами - реализует различные структуры управления электродвигателями различных типов, а также содержит математические модели электродвигателей, которые могут быть опционально подключены вместо реального объекта управления на время отладки. ПО может быть сконфигурировано перед компиляцией для различных аппаратных конфигураций (различных контроллеров и отладочных плат на базе 1921BK01). Для некоторых аппаратных конфигураций ПО может работать только с математическими моделями двигателей, а для конфигураций, поддерживающих управление реальным электродвигателем может по выбору пользователя управлять и реальным объектом (например, конфигурация для отладочного комплекта VectorCARD с инвертором). ПО микроконтроллера разработано для двух сред разработки:
    - бесплатной среды разработки [VectorIDE (Eclipse+GCC+OpenOCD)](http://motorcontrol.ru/production/soft/vector-ide/). Каталог ```MotorControlDemo\EclipseIDE\```.
    - среды разработки CodeMaster++. Каталог ```MotorControlDemo\CodeMaster\```.
- COODEdit4 NIIET edition - редактор словарей CANopen, далее COODEdit (CanOpen Object Dictionary Editor) – программный продукт, позволяющий осуществлять редактирование словарей объектов для CANopen-совместимых устройств с драйвером данной реализации в графическом виде. Подробнее с возможностями программы можно ознакомиться в руководстве пользователя - см. файл ```COODEdit user manual.pdf``` в разделе [Downloads](https://gitflic.ru/project/belerafon/motorcontroldemo-downloads).
- UniCON - управляющий интерфейс пользователя, набор программных средств, позволяющих осуществлять мониторинг (в том числе снятие осциллограмм переходных процессов) и настройку CANopen-совместимых устройств посредством персонального компьютера. UniCON при помощи переходника CAN-USB или USB-UART конвертора взаимодействует через CANopen с ПО микроконтроллера и обеспечивает интерфейс пользователя.
Подробнее с возможностями программы можно ознакомиться в руководстве пользователя - см. файл ```UniCON руководство пользователя.pdf``` в разделе [Downloads](https://gitflic.ru/project/belerafon/motorcontroldemo-downloads). 


## Динамическое ограничение мощности

В скоростных режимах 5, 10, 55, 60 и 101 доступен внешний ограничитель
активной мощности. Он изменяет потолок выхода регулятора скорости, сохраняя
`refs.Iq_ref` абсолютным ограничением тока. При `DebugW3 = 0` поведение
полностью совпадает с прежним.

Настройка выполняется временно в RAM через существующие объекты CANopen:

- `0x5174:0E` (`DebugW3`, целое): `1` — включить; любое другое значение —
  выключить. При каждом сбросе принудительно устанавливается `0`.
- `0x5174:11` (`DebugF1`, float): предел активной мощности в ваттах. Безопасный
  диапазон — `(0; drv_params.power]`; большее значение ограничивается базовой
  мощностью.
- `0x5174:12` (`DebugF2`, float): усиление внешнего интегрального контура.
  `0` выбирает штатное `0.001`; рабочий диапазон `(0; 0.05]`.

Диагностика только для чтения находится в том же объекте: `0x5174:01`
(`Debug1`) — динамический предел тока в IQ24, `0x5174:03` (`Debug2`) — ошибка
мощности в IQ24, `0x5174:05` (`Debug3`) — признак включения и `0x5174:07`
(`Debug4`) — признак активного ограничения. Прошивка не сохраняет эти
настройки в EEPROM.
